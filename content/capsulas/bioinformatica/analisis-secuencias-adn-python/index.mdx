## Módulo 1: Configuración y fundamentos

En este módulo aprenderás a preparar tu entorno de trabajo y a crear tu primera secuencia de ADN con Biopython.

### ¿Qué es Biopython?

Biopython es una librería open-source diseñada para trabajar con datos biológicos en Python. Proporciona herramientas para:

- Manipular secuencias de ADN, ARN y proteínas
- Leer y escribir archivos en formatos estándar (FASTA, GenBank, etc.)
- Acceder a bases de datos biológicas
- Realizar análisis bioinformáticos básicos

### Instalación

```bash
# Crear entorno virtual
python -m venv venv
source venv/bin/activate  # Linux/Mac
# venv\Scripts\activate   # Windows

# Instalar Biopython
pip install biopython
```

<Callout type="info">
Usa siempre un entorno virtual para aislar las dependencias de tu proyecto. Esto evita conflictos entre versiones de librerías.
</Callout>

### Tu primera secuencia

```python
from Bio.Seq import Seq

# Crear una secuencia de ADN
seq = Seq("ATCGATCG")

print(seq)           # ATCGATCG
print(len(seq))      # 8
print(seq.complement())  # TAGCTAG
```

<Callout type="tip">
`Seq` es la clase fundamental de Biopython para trabajar con secuencias. Acepta strings con nucleótidos (A, T, C, G) o aminoácidos.
</Callout>

### Tipos de secuencia

```python
from Bio.Seq import Seq
from Bio.Seq import RNASeq, ProteinSeq

# Secuencia de ADN
dna = Seq("ATCGATCG")

# Secuencia de ARN
rna = Seq("AUCGAUCG")

# Secuencia de proteína
protein = Seq("MVLSPADKTNVKAAWGKVGAHAGEYGAEALERMFLSFPTTKTYFPHFDLSH")
```

## Módulo 2: Operaciones con secuencias

Ahora que conoces las bases, aprenderás las operaciones más importantes para trabajar con secuencias de ADN.

### Complementaria y reversa

```python
from Bio.Seq import Seq

seq = Seq("ATCGATCG")

# Complementaria
print(seq.complement())      # TAGCTAG

# Reversa
print(seq.reverse_complement())  # CGATCGAT

# Transcripción (ADN → ARN)
print(seq.transcribe())      # AUCGAUCG
```

<Callout type="warning">
No confundas `complement()` con `reverse_complement()`. `complement()` solo reemplaza cada base por su complementaria. `reverse_complement()` además invierte el orden. Para análisis de genes, casi siempre necesitas `reverse_complement()`.
</Callout>

### Conteo de bases

```python
from Bio.Seq import Seq
from collections import Counter

seq = Seq("ATCGATCGATCG")

# Contar cada base
count = Counter(str(seq))
print(count)  # Counter({'A': 3, 'T': 3, 'C': 3, 'G': 3})

# Porcentaje de GC
gc_content = (seq.count("G") + seq.count("C")) / len(seq) * 100
print(f"GC: {gc_content:.1f}%")  # GC: 46.2%
```

<Callout type="info">
El contenido de GC es un indicador importante en bioinformática. Organismos con alto contenido de GC suelen ser más termorresistentes.
</Callout>

### Búsqueda de patrones

```python
from Bio.Seq import Seq

seq = Seq("ATCGATCGATCG")

# Buscar subsecuencia
pos = seq.find("GATC")
print(f"Encontrado en posición: {pos}")  # 2

# Contar ocurrencias
count = seq.count("AT")
print(f"Ocurrencias de AT: {count}")  # 2

# Verificar si contiene un patrón
has_pattern = "GATC" in seq
print(f"Contiene GATC: {has_pattern}")  # True
```

## Módulo 3: Lectura y escritura de archivos

Los archivos FASTA y GenBank son los formatos más utilizados en bioinformática. En este módulo aprenderás a leerlos y escribirlos.

### Leyendo archivos FASTA

```python
from Bio import SeqIO

# Leer un archivo FASTA
for record in SeqIO.parse("secuencias.fasta", "fasta"):
    print(f"ID: {record.id}")
    print(f"Secuencia: {record.seq}")
    print(f"Longitud: {len(record.seq)}")
    print("---")
```

<Callout type="tip">
`SeqIO.read()` espera exactamente un registro. Si el archivo tiene múltiples secuencias, usa `SeqIO.parse()` que devuelve un iterador.
</Callout>

### Escribiendo archivos FASTA

```python
from Bio.Seq import Seq
from Bio.SeqRecord import SeqRecord
from Bio import SeqIO

# Crear registros
records = [
    SeqRecord(Seq("ATCGATCG"), id="seq1", description="Secuencia 1"),
    SeqRecord(Seq("GCTAGCTA"), id="seq2", description="Secuencia 2"),
]

# Escribir a archivo
with open("salida.fasta", "w") as f:
    SeqIO.write(records, f, "fasta")
```

### Leyendo archivos GenBank

```python
from Bio import SeqIO

# Leer archivo GenBank
for record in SeqIO.parse("secuencia.gb", "genbank"):
    print(f"ID: {record.id}")
    print(f"Organismo: {record.annotations.get('organism', 'N/A')}")
    print(f"Genes: {len(record.features)}")
```

<Callout type="info">
GenBank contiene más información que FASTA: anotaciones, features (genes, CDS, etc.), y metadatos del organismo.
</Callout>

## Módulo 4: Análisis aplicado

En este último módulo aplicarás todo lo aprendido para resolver problemas reales de bioinformática.

### Análisis de frecuencia de bases

```python
from Bio import SeqIO
from collections import Counter
import matplotlib.pyplot as plt

def analizar_frecuencia(archivo_fasta):
    """Analiza la frecuencia de bases en un archivo FASTA."""
    bases = Counter()

    for record in SeqIO.parse(archivo_fasta, "fasta"):
        for base in str(record.seq):
            bases[base.upper()] += 1

    # Calcular porcentajes
    total = sum(bases.values())
    porcentajes = {b: (c / total) * 100 for b, c in bases.items()}

    # Graficar
    plt.figure(figsize=(8, 5))
    plt.bar(porcentajes.keys(), porcentajes.values(), color=["#2ecc71", "#e74c3c", "#3498db", "#f39c12"])
    plt.title("Frecuencia de Bases")
    plt.ylabel("Porcentaje (%)")
    plt.savefig("frecuencia.png")
    plt.show()

    return porcentajes
```

### Comparación de secuencias

```python
from Bio.Seq import Seq
from Bio import pairwise2
from Bio.pairwise2 import format_alignment

def comparar_secuencias(seq1, seq2):
    """Compara dos secuencias y retorna el alineamiento."""
    alignments = pairwise2.align.globalms(
        str(seq1), str(seq2),
        2,    # match
        -1,   # mismatch
        -0.5, # gap open
        -0.1  # gap extend
    )

    if alignments:
        print(format_alignment(*alignments[0]))
    else:
        print("No se encontraron alineamientos")
```

### Traducción de secuencias

```python
from Bio.Seq import Seq

def traducir_gen(secuencia_dna):
    """Traduce una secuencia de ADN a proteína."""
    seq = Seq(secuencia_dna)

    # Verificar longitud múltiplo de 3
    if len(seq) % 3 != 0:
        print("Advertencia: la secuencia no es múltiplo de 3")

    # Traducir
    proteina = seq.translate()

    # Remover stop codons
    proteina_sin_stop = proteina.rstrip("*")

    return proteina_sin_stop
```

<Callout type="warning">
Siempre verifica que la secuencia sea múltiplo de 3 antes de traducir. Si no lo es, Biopython truncará los últimos nucleótidos.
</Callout>

### Ejercicio práctico

```python
from Bio import SeqIO
from collections import Counter

def analisis_completo(archivo):
    """Realiza un análisis completo de un archivo FASTA."""
    resultados = []

    for record in SeqIO.parse(archivo, "fasta"):
        seq = str(record.seq).upper()

        # Calcular estadísticas
        bases = Counter(seq)
        gc = (bases.get("G", 0) + bases.get("C", 0)) / len(seq) * 100

        resultados.append({
            "id": record.id,
            "longitud": len(seq),
            "gc": round(gc, 2),
            "bases": dict(bases),
        })

    return resultados
```

Usa esta función para analizar tus propios archivos FASTA y extraer información relevante para tu investigación.
