## ¿Qué aprenderás?

En esta cápsula aprenderás a usar Python con Biopython para manipular secuencias de ADN. Cubriremos desde la instalación hasta análisis básicos como conteo de bases, obtención de complementarias y lectura de archivos FASTA.

## Requisitos

- Python 3.8 o superior instalado
- Conocimientos básicos de programación
- Instalar Biopython: `pip install biopython`

## Crear tu primera secuencia

Con Biopython puedes crear objetos `Seq` que representan secuencias biológicas:

```python
from Bio.Seq import Seq

# Crear una secuencia de ADN
seq = Seq("ATGCGATCGATCG")

print(f"Secuencia: {seq}")
print(f"Longitud: {len(seq)}")
```

Salida esperada:

```
Secuencia: ATGCGATCGATCG
Longitud: 13
```

## Conteo de bases

Podemos contar cuántas veces aparece cada base:

```python
from collections import Counter

def contar_bases(secuencia):
    return Counter(str(secuencia))

secuencia = Seq("ATGCGATCGATCGATCG")
conteo = contar_bases(secuencia)

for base, cantidad in sorted(conteo.items()):
    print(f"{base}: {cantidad}")
```

## Complementaria y reversa

Una operación fundamental en bioinformática es obtener la complementaria reversa:

```python
secuencia = Seq("ATGCGATCG")

complementaria = seq.complement()
rev_complementaria = seq.reverse_complement()

print(f"Original:           {seq}")
print(f"Complementaria:     {complementaria}")
print(f"Reversa complementaria: {rev_complementaria}")
```

## Lectura de archivos FASTA

En la práctica real, las secuencias vienen en archivos FASTA:

```python
from Bio import SeqIO

# Leer un archivo FASTA
for record in SeqIO.parse("secuencias.fasta", "fasta"):
    print(f"ID: {record.id}")
    print(f"Secuencia: {record.seq}")
    print(f"Longitud: {len(record.seq)}")
    print("---")
```
